- **A Workflow that adds extra helpers to a deepen or a check** finds CE's prompt files through `~/.claude/plugins/installed_plugins.json`, never a version-numbered path.
- **A session runs the setup it loaded at start until it restarts:** the CE version, plus the `~/.claude/CLAUDE.md` and memory index, which its helper agents get too. CE now updates itself (3.35.3 landed 2026-11-04 18:25 and marked 3.34.0's folder orphaned; sessions started before then run 3.34.0). Start a plan or review step in a fresh session, and restart old sessions at a natural stop (never a busy one mid-work).
- **Removing a hook that refuses calls when its script is missing** (`"onFailure": "block"`): take its `settings.json` entry out first, check a call in this session still runs, then delete the script. A session whose file watcher missed the edit refuses every matching call until it restarts.
- **Auto mode (Claude Code's permission setting) blocks removing a safety check, an irreversible delete, and writes to Claude Code's own config, without Briggsy's own words.** Name every path in the sentence you draft for him: a delete command that bundles a path he didn't name gets refused.
- **Never restore `~/.claude/settings.json` whole from an old commit.** The 10-19 snapshot (config repo `22015c5`) has 15 garbled dashes and no ultracode. Edit it key by key.

- **A peer's unpushed commit under yours:** pushing `main` publishes it too. Commit path-scoped (`git commit -- <paths>`) and check `git log origin/main..HEAD` before a push.

- **Git Bash rewrites a leading-slash argument even for git**: `git sparse-checkout set /projects/x/` stored `C:/Program Files/Git/projects/x/`. Set `MSYS_NO_PATHCONV=1` on any shell-launched command that takes such an argument.
- **In a Write or Edit tool call, a `\uXXXX` in the content arrives as the character itself** (the call's text is JSON), so a typed `"\u2014"` lands in the file as a literal em dash (it did, in this very line, on its first write). To keep a file ASCII, write `String.fromCharCode(0x2014)` in code. Doubling the backslash does not help: the file then holds two. To put the escape itself in a file, build it in a script from `String.fromCharCode(92)` (measured on this line, 2026-11-04). Hit three more times on 2026-11-12: a regex range typed with escapes for 0x7F to 0xFFFF landed with a raw U+FFFF as its end, and two test strings landed with raw dashes (an ASCII-only test caught all three). Write such a range as `[^\x00-\x7e]`, and build test text with `String.fromCodePoint`.
- **The Bash tool halves a doubled backslash even inside a quoted heredoc** (`<<'EOF'`): a script's `\\(` arrived as `\(`, and the JavaScript string it sat in ate the other, so a test regex lost both escapes and passed by accident (playbook-4, 2026-11-05, `select.test.mjs`, found and fixed).
