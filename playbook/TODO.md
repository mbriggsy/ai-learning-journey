## DISTILL CANDIDATES (the hybrid plan step; one `/distill` after the job's closing review)

- **CE's check turns off its own premise challenge for any plan with an origin, such as a brief** (`ce-doc-review/references/personas/product-lens-reviewer.md:15`, `adversarial-document-reviewer.md:17-23`, read on 3.34.0), so a briefed plan never gets "is the problem real?" from CE. - **One Read of a large plan returns a fraction of it**: the 153 KB pay-check spec came back as lines 1 to 269 of 1,059 (a 25,000-token page). A reviewer told to "read the whole plan" who takes one Read reviews a quarter and says nothing.
- **A main-loop window gate rewards whichever arm moves its work into helpers**: b9-6's 16 helpers summed 3,256,161 tokens by peak but about 20.6M at price weights. Gate on a cost both arms pay the same way.
- **"Our worse run against their better run" tests beating, not matching**: under a toy model, a method exactly as good as the incumbent passes it 30.9% of the time.
- **Workflow helpers have neither the Agent nor the Workflow tool**, so a skill that runs Workflows cannot be measured inside one; a head-to-head arm must be a top-level session. And Git Bash rewrites a `claude -p "/skill ..."` prompt into a file path unless `MSYS_NO_PATHCONV=1` is set.
- **A bench that records a child session's environment would publish live API keys.** This laptop's sessions carry `OPENAI_API_KEY` and `CONTEXT7_API_KEY` (names checked 2026-11-01), stripping `CLAUDE`-prefixed variables leaves them, and the repo is public. - **Naming the last line works.** Each reviewer got the plan's last line number and its opening words, a 160-line paging rule and a quoted-inventory return; all ten in the hybrid plan's check (two rounds) reached the last line, 609 and then 620.
- **A platform record can cover less than its name says**: `claude -p`'s `permission_denials` lists only the final turn's denials (U1 probe, 8 then 0 for the same decoys), so a gate reading it alone passes a session whose denials ran earlier. Read the transcript.

The lookup must refuse a short input: a repo path given short silently dropped every long-form rule, and the probe, built from the same short path, would still have passed (round-1 review).
- **Prove a removal against a control from the same source**: a removed MCP tool and a never-loaded one answer alike ("No such tool available"), so the probe's `mcp` check passes only when a claude.ai connector of the same kind is offered.
- **Make the probe try every rule the fix writes, not just the one that failed**: round 2 found no decoy for the 8.3 Edit and Write rules under `~/.claude` (exact-file rules with a short last name, `SETTIN~1.JSO`, included); the probe now builds its decoys from the same `spellings` the deny set uses.

- **Review fixes can be proved vacuous by mutants**: the U1 review's vacuity lens planted each mutant in a copy and ran the tests (a Rise taken over helper turns, a dropped effort field, a removed SECRET word) and every surviving one became a fixture.
