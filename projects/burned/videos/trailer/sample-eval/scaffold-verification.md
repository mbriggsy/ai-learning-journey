## Execution-time amendment: `videos/trailer/.npmrc`

**Symptom.** Plain `pnpm install --dir videos/trailer` from the BURNED
project root completed in 566ms with no output and no `node_modules/`
created. Reinvoking with `--ignore-workspace` ran the real install.

**Root cause.** BURNED's repo root carries `pnpm-workspace.yaml` with
`onlyBuiltDependencies: sharp` (the BURNED-side allowlist controlling
which postinstall build scripts may run). That file makes pnpm treat
the parent directory as a workspace boundary. Because the file declares
no `packages:` field, pnpm sees nothing covering `videos/trailer/` and
treats the directory as "not in this workspace" — install is a no-op.

UMB v3 doesn't hit this because UMB has no `pnpm-workspace.yaml`. The
plan called for mirroring UMB exactly, but the BURNED workspace context
is a real environmental difference.

**Fix.** Added `videos/trailer/.npmrc` with `ignore-workspace=true`.
Plain `pnpm install` (and any future `pnpm --dir videos/trailer ...`
invocation) now correctly bypasses the parent workspace.

**Alternative considered + rejected.** Adding `videos/trailer` to the
BURNED root `pnpm-workspace.yaml` `packages:` field would also make
install work, but that bakes the trailer into the BURNED workspace —
shared `node_modules`, shared `pnpm-lock.yaml`, no longer isolated.
That violates roadmap ADR #2 (isolated trailer package). The `.npmrc`
keeps the trailer truly standalone.

**Plan delta.** Unit 0.1 Files list amended to include `.npmrc`.
