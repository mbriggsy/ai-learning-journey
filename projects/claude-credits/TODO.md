# claude-credits — public showcase site

A Vercel-hosted, GSAP-driven, drippy-wet web showcase that visualizes the credit data from the `claude-credit` CLI across all of Briggsy's projects. Built to look like a fucking sick stat sheet — counters ticking up, liquid SVG morphs, ripples, the whole production.

**This doc IS the TODO for a fresh session in `projects/claude-credits/`. Read it top to bottom before doing anything.**

## The brief (don't lose this)

Briggsy asked for: "A Vercel-hosted drippy GSAPy wet set of web pages with fucking sick graphics that shows the stats of all the sub-projects in this mono-repo. And it gets updated, maybe every squeaky round. And I mean fuck sick graphics, animations, pulses, flows, whatever. Like I mean, let's show the fucking world how fucking amazing you are!"

**The bar:** "so fucking slick that water beads off it." Picture water beading on a deep-gloss car hood, sexy silhouette in the back, 70s/80s commercial mood. Polished WITH attitude. Not "clean," not "minimal" — *commercial-grade gloss*.

**Failure condition:** if a first-time visitor reacts to "wow Claude built this" instead of "wow this product is slick" — the bar is missed. The craft has to be invisible; the product stands on its own.

## Phase 0 — Fill data gaps in `tools/claude-credit/` (~30 min, do this FIRST)

These three additions unlock significantly cooler visuals for trivial effort. Add them before building the site so the data contract is stable.

### 0.1 — Add `firstCommit` / `lastCommit` per project
**File:** `tools/claude-credit/src/git-stats.ts`, `src/taxonomy.ts`

Add to `GitStats`:
```ts
firstCommitISO: string | null;
lastCommitISO: string | null;
projectAgeDays: number | null;
```

Implementation in `collectGitStats`: two `git log` calls scoped to the subdir.
- First: `git -C <root> log --pretty=format:%aI --reverse -- . | head -1`
- Last: `git -C <root> log -1 --pretty=format:%aI -- .`
- Age: diff in days.

Unlocks: "BURNED · born 47 days ago" timeline ribbon on project tiles.

### 0.2 — Add asset-bytes-by-kind on disk (NOT just git events)
**File:** `tools/claude-credit/src/counter.ts` or `src/report.ts`

While aggregating `CategorizedFile[]`, sum bytes per asset subcategory and surface in `ProjectReport.assetBytesByKind`:
```ts
assetBytesByKind: {
  images: number;
  audio: number;
  video: number;
  fonts: number;
  'misc-media': number;
}
```

Unlocks: hero pie/donut chart "211 MB images · 133 MB video · 37 MB audio."

### 0.3 — Add `topSubcategories` pre-computed
**File:** `tools/claude-credit/src/report.ts`

After tier aggregation, add to `ProjectReport`:
```ts
topSubcategories: Array<{
  tier: Tier;
  category: string;
  subcategory: string;
  bytes: number;
  files: number;
  lines: number;
}>;  // sorted desc by bytes, top 5
```

Unlocks: tile highlights without per-tile iteration in the renderer.

### 0.4 — Bump version + rebuild
- Bump `tools/claude-credit/package.json` to `0.2.0`
- `pnpm build` from `tools/claude-credit/`
- Verify with `claude-credit C:/Users/brigg/ai-learning-journey/projects/burned --json | jq '.git.projectAgeDays, .assetBytesByKind, .topSubcategories'`

## Phase 3 — Hero counter (the first "wow")

Landing page hero. ONE animated counter ticking up to the lifetime authored-lines total (currently 421,633). When the page loads:

1. **Counter starts at 0**, tweens to target over ~2.4s with `power3.out`.
2. **Background**: subtle animated gradient mesh (deep teal → midnight) with slow horizontal drift. Pure CSS conic-gradient + GSAP-driven CSS variable. No WebGL in v1.
3. **Behind the number**: a column of falling water droplets, generated as SVG circles, animated downward with stagger. Each droplet fades out at the bottom. Loops.
4. **Number typography**: massive (clamp 8rem to 22rem), variable-width display font, tabular-nums for stable digit width during tick-up.
5. **Underneath**: smaller stats animate in 200ms each, staggered:
   - "across 9 projects"
   - "with 1,891 files and 430 MB of work"
   - "1,027 commits and counting"
6. **Cursor**: a subtle parallax that shifts the droplet column based on cursor X position.

**No scroll-jacking, no auto-play sound, no popup.** Just instant fluid load.

## Phase 8 — Visual polish iteration

This is where the bar gets met or missed. After Phase 7 ships a working site, iterate:

1. **Side-by-side compare** against reference sites (Apple, Stripe, Linear, Awwwards-class). What do they have that we don't?
2. **Run the "could a stranger watch a 30-second screen recording and say 'that's slick'?" test.** If no — diagnose where the friction is.
3. **Common polish wins** (in priority order):
   - Counter easing curves — tweak `ease` until ticks feel weighty, not mechanical
   - Droplet timing — staggered, slightly randomized, never robotic
   - Hover micro-interactions — should feel inevitable, not bolted on
   - Type leading and tracking on big numbers — kerning matters at 20rem
   - Transition between routes — fade vs slide vs morph; pick one and commit
4. **No new features until the bar is hit.** Add motion polish, not surface area.

## Visual system (the WOW dictionary)

**Color palette** (Claude owns, Briggsy can't see):
- Background: `#0a1a26` (deep midnight teal) → `#0f2839` (gradient stop)
- Surface (glass): `rgba(20, 40, 56, 0.6)` with `backdrop-filter: blur(20px)`
- Accent primary: `#ff8c42` (warm orange, BURNED-adjacent)
- Accent iridescent: animated conic-gradient cycling through teal/orange/violet for hover states (oil-on-water)
- Text primary: `#f5e9d3` (cream)
- Text secondary: `#9eb4c4` (cool gray-blue)
- Stat highlight: `#ffd34e` (warm gold)
- Danger / discard: `#d4524c` (used for discarded-asset callouts)

**Typography:**
- Display: **Satoshi Variable** (free at fontshare.com) — for hero numbers + tile titles
- UI: **Inter Variable**
- Mono: **JetBrains Mono Variable** — for stat callouts where digit alignment matters

**Motion principles:**
- Ease default: `power3.out` (organic deceleration)
- Counter ease: `power2.out` with `duration: 2.4`
- Reveal-on-scroll: `power3.out` with `duration: 0.8`, `y: 40` to `y: 0`, opacity 0 to 1
- Hover: `power2.out` with `duration: 0.25`
- NEVER use `linear` ease. NEVER stack > 3 simultaneous animations on one element.
- All animations respect `prefers-reduced-motion` — fall back to instant state changes.

**Named "wow moments"** (one per surface, no more):
- Landing: the hero counter + falling droplets
- Project tile: the cursor-tracked ripple on hover
- Project detail: the asset donut DrawSVG reveal
- Route transition: a single horizontal "wipe" using GSAP `Flip` plugin
