— Phases · 01 → 06

Six phases.
Six gates.
No skipping.

Each phase is fully agent-driven. ATC kicks off, answers when the agent asks, and approves at the gate. The gate is the catch — not constant human vigilance. /brief and /distill form the feedback loop that compounds team memory build over build — bugs the team has paid for once don't get paid for twice.

Phase 01
01-prd.md

PRD

The contract lands. PRD + RTM together — narrative spec plus row-per-behavior matrix. Inherited (Ch1 reverse-engineering) or authored fresh (Ch2). Challenger panel reviews before lock.

Tower
Read both end to end. Hunt for holes, implicit assumptions, unresolved correctness flags. Lock when conviction holds.
Cockpit
Run the panel. Compose the contract. Surface every guess for resolution before lock.
Gate
Both docs read end to end · nothing to kick back · every behavior has an RTM row.
PRD + RTM
Phase 02
02-plan.md · draft

Plans

Implementation broken into phased plan files. Each plan captures decisions — goal, RTM rows satisfied, dependencies, files, approach, patterns, test scenarios, verification, open questions. Decisions, not code.

Tower
Kick off the planning skill. Watch context window. Call the next phase plan.
Cockpit
Read the contract. Draft the full series before deepening starts. Never write implementation.
Gate
Full series drafted · every RTM row mapped · cross-phase consistency held.
plans/*.md (drafted)
Phase 03
02-plan.md · deepen

Deepen

Each plan goes through a challenger panel — correctness, feasibility, scope, security, coherence, adversarial. A synthesizer integrates findings and strengthens the plan. Drafted-but-undeepened plans are wishes.

Tower
Sequence the deepening, one plan at a time. Approve advance to next plan.
Cockpit
Run the panel. Resolve open questions or defer with reasons. Update the plan in place.
Gate
All plans deepened · open questions resolved or deferred · no contradictions across phases.
plans/*.md (build-ready)
Phase 04
03-execute.md

Execute

The agent reads each plan and translates it into code — one phase end to end before the next begins. Atomic commits, runtime verification, never papering over divergence in code.

Tower
Start it. Answer when the agent asks. Approve at the gate — the gate is the catch, not your eyeballs.
Cockpit
/brief at the top. One task at a time. Fix the right artifact when reality diverges. Report clearance when criteria hold.
Gate
Every plan executed · every task verified at runtime · plan or contract deltas written back.
working code
Phase 05
04-review.md

Review

A code-review panel pressure-tests the build from multiple angles. Findings triage into fix, defer, or reject with reason recorded. /distill captures lessons into team memory.

Tower
Aim the panel. Decide contested findings — once, recorded, move on.
Cockpit
Run the panel. Resolve actionable findings. Run /distill at session end.
Gate
Every finding triaged · runtime verification holds · /distill has run.
reviewed code + brief delta
Phase 06
05-evidence.md

Evidence

The build proves it shipped wow-grade. RTM closed, runtime tests captured, parity proved (Ch1) or AC met (Ch2), framework run end-to-end, documentation that lets a new engineer own it. ATC walks the plane.

Tower
You ARE the panel here. Run the wow check. Sign off — or send the build back.
Cockpit
Assemble the package. Re-run failing phases until the package clears the bar.
Gate · Ship
Package complete · the wow check passes. No half-ship, no ship-with-asterisks.

Doctrine 03 OF 03 · NON-NEGOTIABLE
— The Bar

Three rules.
No bending.

Half the value of the methodology is the discipline to hold these when expedience pulls otherwise. Refuse to short-circuit. Refuse to ship six-of-ten. Refuse to break clean room.

Rule 01

Refuse to short-circuit phases.

Phases run in order. A defect at phase 04 does not get pulled forward into phase 05. The cost to fix in place is one update; the cost mid-flight is a re-run of every phase that depended on the broken assumption.

Rule 02

Wow-grade or it doesn’t ship.

“The best ETL engineers on the team look at this and say wow.” That is the bar — not “fine,” not “ships.” If the build fails the wow check at evidence, it doesn’t ship. Re-run the failing phase until it clears.

Rule 03

The contract is load-bearing.

PRD + RTM is the only input downstream phases see. Clean room (Ch1) means the agent never peeks at legacy code. If the contract has holes, every downstream artifact inherits the same holes.
