# Impeccable Design Skills

21 design skills from [pbakaus/impeccable](https://github.com/pbakaus/impeccable), installed locally to this project only.

```bash
# Already installed. To reinstall if missing:
npx skills add pbakaus/impeccable
```

**Setup:** Run `/teach-impeccable` first — it gathers project context and writes `.impeccable.md` (design tokens, brand personality, accessibility rules). All other skills read this file before doing work.

## Skills

| Skill | What it does |
|-------|-------------|
| `/critique` | Full design evaluation (hierarchy, heuristics, emotional resonance) |
| `/audit` | Technical quality checks (a11y, perf, theming) with P0-P3 severity |
| `/polish` | Final quality pass — alignment, spacing, consistency, micro-details |
| `/animate` | Purposeful animations and micro-interactions |
| `/delight` | Moments of joy — easter eggs, personality, unexpected touches |
| `/overdrive` | Push past conventional limits — shaders, spring physics, scroll-driven |
| `/bolder` | Amplify safe/boring designs for visual impact |
| `/quieter` | Tone down overstimulating designs while preserving quality |
| `/colorize` | Add strategic color to monochromatic designs |
| `/typeset` | Fix typography — fonts, hierarchy, sizing, readability |
| `/clarify` | Improve UX copy, error messages, labels, microcopy |
| `/arrange` | Fix layout, spacing, visual rhythm, hierarchy |
| `/adapt` | Responsive design across devices and screen sizes |
| `/harden` | Resilience — error handling, i18n, text overflow, edge cases |
| `/optimize` | UI performance — Core Web Vitals, bundle size, rendering |
| `/normalize` | Realign UI to design system tokens and patterns |
| `/extract` | Extract reusable components and design tokens |
| `/distill-design` | Strip designs to essence (renamed from `/distill` to avoid collision with our technical insights `/distill` skill) |
| `/frontend-design` | Create distinctive interfaces avoiding AI slop aesthetics |
| `/onboard` | First-run experiences, empty states, guided tours |
| `/teach-impeccable` | One-time setup — generates `.impeccable.md` |

## Files

- `.impeccable.md` — project design context (generated by `/teach-impeccable`)
- `.agents/skills/` — actual SKILL.md files
- `skills/` — symlinks to `.agents/skills/`
- `skills-lock.json` — version tracking with integrity hashes

These are plugin infrastructure — not committed to git.
