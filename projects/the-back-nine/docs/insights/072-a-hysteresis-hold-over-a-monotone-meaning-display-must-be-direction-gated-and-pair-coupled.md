# 072 — a hysteresis hold over a monotone-meaning display must be direction-gated and pair-coupled (prove it with a property sweep whose legal set derives from the producer)

**Date:** 2026-07-09 · **Unit:** U12 closers (the sharpen-loop ultramode review) · **Severity:** P1, the cardinal-sin class

## Problem

The U12 sticky-display seam (`resolveStickyDisplay`, memoryModel.ts) held ANY one-step
display flip whose new reading landed within EPS of a flip edge. Its comment claimed the
hold direction was "CONSERVATIVE by construction" — true only for a RISING reading. A
reading **falling** exactly onto an edge held the **rosier** prior:

- prev `{9, over-funded}`, one edit drops raw survival to quantized **0.85** →
  `{9, on-track}` with `stateMarginToEdge` 0 → the state hold kept **over-funded**, and
  the hero kept rendering "more than enough… better than 9 in 10" over a true 85%
  reading. The count guard (`|rawX − prevX| ≤ 1`) was **blinded by the 9-cap**: both
  bands display 9, so a two-band fall reads as Δ=0. Undisclosed everywhere — the panel
  echo's `worsened` flag keys on `xOfTen` (9 == 9, never fires), and the echo reads the
  same held triple.
- prev `{9, on-track}`, raw falls to **0.75** → `{8, borderline}`: the count hold kept 9
  while the state adopted borderline → **`{9, borderline}`** — a pairing `buildHeadline`
  can never emit (borderline caps at 8). Two "independent margins" composed a verdict
  from two different worlds (the 056 class, inside one sentence).

Eight of twelve review lenses independently converged on this one defect (the 017
convergence beacon), every refuter voting confirm 3-0.

## Fix (three laws, one seam)

1. **The conservative-direction law:** every hold is direction-gated — hold only a
   display LESS optimistic than the raw reading (the lower count, the lower-ranked word,
   the lower dollar). Band order comes from the engine's own exported
   `STATE_OPTIMISM_RANK` (confidence.ts) — never re-derived UI/store-side.
2. **The sibling sweep at fold time:** the DOLLAR hold had the same blindness and **no
   finder flagged it** — a falling `room` figure held the rosier dollar. Same law, same
   line. When a defect is a *shape*, grep the seam for every same-shape sibling before
   closing (insight 054's move, applied to a finding).
3. **SYMMETRIC pair coupling:** each unit may hold only while the other is STABLE
   (unchanged) or itself held — otherwise both adopt. This makes the displayed pair
   provably either prev's pair or raw's pair, both engine-emittable.

## Root Cause — the part enumeration missed; why the property sweep is the real proof

My first fix used **one-sided** coupling (count-holds require a stable word), verified by
hand-enumerating the edge cases. The full-grid property sweep — every `(prev, raw)`
quantized pair, readings generated by `summarize()` itself — immediately produced
`{9, borderline}` through the **mirror** path the enumeration missed: at the 0.98 edge
(prev `{8, borderline}`, raw `{9, over-funded}`) the *state* hold fires (stateMargin 0)
while the *count* adopts (xMargin 0.03) — word held, count moved, impossible pair again.

Two properties, both derived from the producer (nothing hand-typed to drift):

- **Never-rosier:** rank(displayed.state) ≤ rank(raw.state), displayed count/dollar ≤ raw.
- **Emittable pairing:** `(state, count)` ∈ the set collected from the SAME sweep's raw
  headlines (the legal set is self-derived — the test re-derives no band math).

The sweep kills every mutant the named pins kill, plus the classes nobody named
(4 sticky mutants + it caught the live mirror bug during the fold itself).

## Key Insight

- A sticky/hysteresis/debounce display over a scale with a MEANING direction
  (better/worse, safe/unsafe) is not neutral smoothing: state **which direction may
  hold** and gate it, or the anti-flicker seam becomes an optimism ratchet on exactly
  the falling readings the honesty contract exists for.
- When N displayed fields are projections of ONE underlying value, N independent holds
  can compose a value that never existed. Couple them **symmetrically** (hold only
  beside stable-or-held siblings) so the composite is always a true projection.
- Prove both with a **generator-derived property sweep**, not enumerated pins —
  enumeration missed the mirror case *inside this very fix*. Pins name the story;
  the sweep holds the law.
- A "conservative by construction" comment is a CLAIM about a gate (insight 044's
  class) — here the gate didn't exist for half the input space.
