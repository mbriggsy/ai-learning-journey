**Tool 1: Texture Atlas Builder (`tools/build-atlas.ts`)**

This tool takes multiple PNG files and packs them into a single atlas PNG + a JSON descriptor file in PixiJS/TexturePacker format.

**Input:** All PNG files in `public/assets/sprites/` (car sprites after processing)
**Output:**
- `public/assets/atlas/sprites.png` — packed atlas image
- `public/assets/atlas/sprites.json` — PixiJS-compatible JSON descriptor

**PixiJS Atlas JSON format** (TexturePacker format):

```json
{
  "frames": {
    "car-player-red.png": {
      "frame": { "x": 0, "y": 0, "w": 128, "h": 128 },
      "rotated": false,
      "trimmed": false,
      "spriteSourceSize": { "x": 0, "y": 0, "w": 128, "h": 128 },
      "sourceSize": { "w": 128, "h": 128 }
    },
    "car-player-blue.png": {
      "frame": { "x": 128, "y": 0, "w": 128, "h": 128 },
      "rotated": false,
      "trimmed": false,
      "spriteSourceSize": { "x": 0, "y": 0, "w": 128, "h": 128 },
      "sourceSize": { "w": 128, "h": 128 }
    }
  },
  "meta": {
    "app": "top-down-racer-asset-pipeline",
    "version": "1.0",
    "image": "sprites.png",
    "format": "RGBA8888",
    "size": { "w": 512, "h": 512 },
    "scale": "1"
  }
}
```

**Atlas packing algorithm:**

Use a simple shelf-packing algorithm (not optimal but deterministic and simple):

1. Read all PNG files from the input directory
2. Get dimensions of each using `sharp(file).metadata()`
3. Sort by height descending (tallest first)
4. Pack into rows (shelves): place sprites left-to-right, start a new row when the current row is full
5. Atlas size: use the smallest power-of-2 dimensions that fit all sprites (start at 256×256, double as needed, cap at 4096×4096)
6. Composite all sprites onto a single Sharp image using `sharp.composite()`
7. Write the atlas PNG and JSON descriptor

**Functions to implement:**

```typescript

  filename: string;
  width: number;
  height: number;
  x: number;  // position in atlas
```

**Edge cases:**
- If input directory is empty: print message "No sprites to pack", exit 0
- If a single sprite is larger than 4096×4096: error
- If total sprites don't fit in 4096×4096: error (unlikely with car sprites)

**Tool 2: Asset Manifest Generator (`tools/generate-manifest.ts`)**

Scans `public/assets/` and generates a fully typed TypeScript file at `src/assets/manifest.ts`.

**How it works:**

1. Recursively scan `public/assets/` for all asset files (PNG, JSON, WAV, ONNX)
2. Organize into categories based on subdirectory:
   - `sprites/*.png` → `cars` category
   - `tracks/*.png` → `tracks` category
   - `textures/*.png` → `textures` category
   - `audio/*.wav` → `audio` category
   - `atlas/*.json` → `atlas` category (just the JSON path, not the PNG — PixiJS loads the JSON which references the PNG)
3. Generate TypeScript with `as const` assertion

**Output format** (the generated `src/assets/manifest.ts`):

```typescript
/**
 * Typed asset manifest — auto-generated by tools/generate-manifest.ts
 * DO NOT EDIT MANUALLY. Run `pnpm run manifest` to regenerate.
 */
export const ASSETS = {
  cars: {
    'car-player-red': 'assets/sprites/car-player-red.png',
    'car-player-blue': 'assets/sprites/car-player-blue.png',
    'car-ai-white': 'assets/sprites/car-ai-white.png',
  },
  tracks: {
    'track01-bg': 'assets/tracks/track01-bg.png',
    'track02-bg': 'assets/tracks/track02-bg.png',
  },
  textures: {
    'asphalt-dry': 'assets/textures/asphalt-dry.png',
    'grass': 'assets/textures/grass.png',
  },
  audio: {
    'engine-idle': 'assets/audio/engine-idle.wav',
  },
  atlas: {
    sprites: 'assets/atlas/sprites.json',
  },
} as const;

export type AssetManifest = typeof ASSETS;
export type CarAssetKey = keyof typeof ASSETS.cars;
export type TrackAssetKey = keyof typeof ASSETS.tracks;
export type TextureAssetKey = keyof typeof ASSETS.textures;
export type AudioAssetKey = keyof typeof ASSETS.audio;
export type AtlasAssetKey = keyof typeof ASSETS.atlas;
```

**Key rules for manifest generation:**
- Asset keys are derived from filenames: strip extension, use as key (e.g., `car-player-red.png` → `'car-player-red'`)
- Paths are relative to `public/` (since Vite serves from `public/`)
- The file must be valid TypeScript that compiles with `tsc --noEmit`
- Include the `as const` assertion for maximum type narrowing
- Export type aliases for each category for downstream consumption

**Functions to implement:**

```typescript
/** Scan a directory for files matching extensions, return paths relative to public/ */
async function scanAssetDir(dir: string, extensions: string[]): Promise<{ key: string, path: string }[]>

/** Generate the full TypeScript source for the manifest */
function generateManifestSource(assets: { cars: ..., tracks: ..., textures: ..., audio: ..., atlas: ... }): string

/** Main: scan all directories, generate manifest, write to src/assets/manifest.ts */
async function main(): Promise<void>
```

**Edge cases:**
- If `public/assets/` has no files: generate manifest with empty categories (still valid TypeScript)
- If a subdirectory doesn't exist: skip it, empty category in manifest
- Overwrite existing `src/assets/manifest.ts` — it's auto-generated
