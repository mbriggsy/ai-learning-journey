## Installation Steps

### Step 1: Install OpenClaw

Run in PowerShell (Admin):

```powershell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

During onboarding wizard:
- Declined zsh shell completion (Windows only — not applicable)
- Chose to install gateway service

### Step 2: Install Gateway Service

First attempt failed because PowerShell wasn't elevated. Re-ran as Administrator:

```powershell
openclaw doctor --fix
```

This installed the gateway as a **Windows Scheduled Task**.

### Step 3: Fix Discord Crash (Error 4014)

Gateway crashed immediately on startup due to Discord bot misconfiguration. Temporarily disabled Discord:

```powershell
openclaw config set channels.discord.enabled false
```

This allowed the gateway to start cleanly while Discord was being properly configured.

### Step 4: Start Gateway Manually

The Windows Scheduled Task failed with *"system cannot find the file specified"*. Workaround — run the gateway script directly:

```powershell
C:\Users\brigg\.openclaw\gateway.cmd
```

> ⚠️ **Note:** This keeps the gateway running only while that PowerShell window is open. The Scheduled Task auto-start issue still needs to be resolved in a future session.

## Discord Bot Setup

1. **Created Discord Application** — https://discord.com/developers/applications → New Application
2. **Enabled Bot Intents** — Bot → Privileged Gateway Intents → Presence, Server Members, Message Content all ON
3. **Set Bot Permissions** — View Channels, Send Messages, Read Message History
4. **Generated OAuth2 URL** — OAuth2 → URL Generator → scopes: bot
5. **Created Discord Server** — "Harry's Lair" — private server for bot interaction
6. **Added Bot Token to OpenClaw:**
   ```powershell
   openclaw channels add --channel discord --token <token>
   ```
7. **Configured Channel Allowlist** — `openclaw configure` → Channels → Discord → Modify Settings → Allowlist → added #general channel ID
